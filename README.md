# Lightning-Detector
Its a detector that can detect lightning strikes 
And with just few steps you can also able to build this and it might save your live
to build this detector you need to get all the parts listed in the BOM and the PCB the gerber file is also given in the production file

After getting all the components solder all the components and you are done now whenever you scenic some lightning strikes just turn on this device by the switch and you can see the distance of the strikes and how strong the strikes are also it can count theme.
I think this device can warn you by sowing the strength of the strikes.
